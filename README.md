## 简介

2025年下半年，我们萌生制作赣语通用输入法的想法。在此之前，我们对其他汉语的输入法有过一定观察。起初，我们把赣语语音与文字的对应依靠多种资料进行了整理，建立了最基本的词典。但是很快，我们认为这样的简单对应似乎还不足以适合我们现有的需求。我们希望以另一种形式系统性整理保存赣语各个点位的语料。因此就有了我们现有的项目设想：不仅是可以以赣语语音输入汉字，还要能让使用者可以用赣语思维顺利输入普通话，也可以让赣语不太熟练但是听过的年轻一代，抑或只是对赣语感兴趣的爱好者，都可以借此输入地道的赣语文本。

由此可见，我们的“通用“有三个含义。第一，是在赣语各个点位通用。第二，是赣语普通话之间通用。第三，是技术意义上全平台通用。

我们项目尽可能使用地道的本字、正字，兼顾民间常用写法，可以引导用户一种规范且兼顾通俗的地方汉语文本。

### 特色

除基本词典之外，已经实现的功能有：

- 对字词等进行标音，拼音方案和调号将在下面解释。本套拼音方案大体上是接近汉语拼音方案的，主要是出于低学习成本上手的考虑。
- 兼容普通话输入法使用者容易使用的习惯拼写方法。当然，最终显示还是以本套方案拼音为准。
- 对普通话常用词与赣语点位常用词进行对应。互相进行解释。当被对应的一方被索引到候选词列表时，另一方也会出现，以方便使用赣语输入普通话或使用普通话输入赣语的目的。
- 对于词汇文白读音，新派老派读音，或者一些另读进行兼容输入和清晰标注。

目前，我们已经建成13个词典点位。另希望就别的点位进行充分扩展。欢迎参与我们的词典增添与校正！

## 安装方法

输入法主体覆盖 Linux、Android、Windows 和 macOS。如使用通用 Rime 资源包，安装方法见 Rime 章节。

从 [Releases](https://github.com/Doohaey/GonnyuGeneralIME/releases) 下载与系统相符或者对应区域的文件。

### macOS

从 [Releases](https://github.com/Doohaey/GonnyuGeneralIME/releases) 下载 `GonnyuGeneralIME-版本号-macos.pkg`，双击打开并完成安装。

若安装后未自动显示：打开“系统设置 → 键盘 → 文本输入 → 编辑…”，点击“+”，搜索并添加“Gonnyu”，再从输入法菜单切换至它。升级会保留用户词库。

由于系统特性，碰到系统设置中添加输入法时列表中没有，添加后还无法切换等情况，请尝试注销重登。

### iOS

iOS 上使用输入法时，除法国用户外，请直接到app store下载＂赣语输入法＂。

### Android

下载 `GonnyuGeneralIME-版本号-android.apk`，在 Android 系统中打开并安装。首次打开应用后，按应用内引导启用“赣语输入法”，再在系统输入法选择器中切换至它。

### Windows

下载并运行 `GonnyuGeneralIME-版本号-windows-installer.exe`，按安装向导完成安装。随后在“设置 → 时间和语言 → 语言和区域 → 中文（简体） → 键盘”中添加“Gannyu”。

### Linux：Fcitx5

一式与二式分别打包：一式下载 `GonnyuGeneralIME-版本号-fcitx5-gonnyu.tar.gz`，二式下载 `GonnyuGeneralIME-版本号-fcitx5-gonnyu_II.tar.gz`。解压后运行包内安装程序：

```sh
mkdir GonnyuGeneralIME-fcitx5
tar -xzf GonnyuGeneralIME-版本号-fcitx5-gonnyu.tar.gz -C GonnyuGeneralIME-fcitx5
cd GonnyuGeneralIME-fcitx5
./install.sh
```

重启 Fcitx5（`fcitx5 -r`）或注销后重新登录，并在 `fcitx5-configtool` 中添加“GonnyuGeneralIME / 赣语（一式）”或“GonnyuGeneralIME (Compositional) / 赣语（二式）”。

### Rime

每个地区提供两个独立安装包：

- `GonnyuGeneralIME-版本号-rime-地区.zip`：一式（汉拼式）
- `GonnyuGeneralIME-版本号-rime-地区-II.zip`：二式（组合式）

只使用其中一种方案时，下载对应 ZIP 即可。想同时使用一式、二式时，把两个 ZIP 都安装到同一个 Rime 用户目录。

**Windows 小狼毫**

1. 下载需要的 ZIP。
2. 解压后，把文件复制到 `%APPDATA%\Rime`。
3. 在输入法菜单中选择“重新部署”。
4. 在方案菜单中选择“赣语－地区（一式·汉拼式）”或“赣语－地区（二式·组合式）”。

**Linux Fcitx5 Rime**

1. 下载需要的 ZIP。
2. 解压后，把文件复制到 `~/.local/share/fcitx5/rime/`。
3. 重新部署 Rime。
4. 在方案菜单中选择所需方案。

**iOS、Android**

在已安装的 Rime 前端中使用导入或部署功能载入所需 ZIP，然后从方案菜单选择方案。

如果同时安装一式、二式两个包，请在 `default.custom.yaml` 的方案列表中保留两个方案。

### 输入设置

各开关默认开启，读音模式默认为“新老兼有”。设置切换后生效，无需重新安装或部署。

| 设置项目 | 作用 |
| --- | --- |
| 副标题 | 显示或隐藏候选词的读音和注释。 |
| 赣普词语连带 | 控制赣语词与官话对应词的连带候选及相关注释；关闭时过滤官话词，保留单字候选。 |
| 同义词连带 | 控制同义词连带候选及相关注释。与赣普词语连带、副标题分别设置。 |
| 模糊匹配 | 总开关，下属“普拼兼容”“文白匹配”“其他模糊规则”。普拼兼容允许用普通话拼音匹配词语；文白匹配允许文读、白读互相匹配，关闭后保留文白标题；其他模糊规则控制特殊 i、e、o 音位兼容（ï、ê、ô）之外的模糊匹配。 |
| 读音模式 | 选择“新老兼有”“新派”或“老派”，同时调整读音匹配和副标题中的新老派显示。 |
| 方案 | 选择一式（汉拼式）或二式（组合式）；地区未启用二式时只能选一式。 |

模糊匹配关闭后，三个子项停止生效并保留选择；移动端子项变灰。

| 平台 | 操作入口 |
| --- | --- |
| macOS | 点击菜单栏“赣·地区”，打开“输入设置”。 |
| Windows | 使用赣语输入法时，在语言栏打开“输入设置”。 |
| iOS、Android | 打开赣语输入法主应用，在“输入设置”中调整。 |
| Rime | 打开所用前端的方案选单，切换对应开关或读音模式。 |
| Linux Fcitx5 原生版 | 安装“gonnyu”（一式·汉拼式）或“gonnyu_II”（二式·组合式）独立输入法；不提供运行时方案开关。 |

## 本输入法采用的通用赣语拼音方案

本项目设计的通用赣语拼音除尽可能涵盖各点位各音位前提下，处理了一批必要的音位对立，还对赣语内部部分点位的鼻化韵、浊音进行合理化表达。当然，考虑新派归并特点以及输入方便，拼音不对所有语音细节（如气声或弛声等）进行准确刻画，也合并了一批在各个点位无实际差别/仅仅是异读的音值。

本输入法提供一式（汉拼式）与二式（组合式）两套并行方案，可在输入设置中切换。

为符合输入实际，本项目所使用的通用赣语拼音(gon-pin)一式在反映赣语发声实际的基础上，尽可能贴近《汉语拼音方案》的拼写模式。

1. 在以上音节成分之外，实际还参考某些文献和生活中发现的音变做了一些扩充表示。其中，包括了1935年所做的语言调查中所记录的一些发音，以及一些特殊的[-n]、[-ng]韵尾音变。
2. 一般来说，对于南昌音系，我们以熊正辉《南昌方言词典》为参考标准。但《南昌方言词典》中也存在少部分口音过于老式、口音过于小众、听感不合实际问题。对此，进行了一定校正。如以赣拼表示的南昌音节fui，在《南昌音系》（1935）资料中记音为[ɸui]，但是在熊正辉《南昌方言词典》中记音为[fɨi]。本音节老派听感不接近于"fei".为了保证输入符合听感，且有依据，采用《南昌音系》(1935)ipa记法。
3.方案切换在输入设置中完成；未启用二式的地区只有一式可选。
